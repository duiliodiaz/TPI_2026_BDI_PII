POST /api/Clientes -> que devuelva el cliente en vez de un mensaje
POST /api/Productos -> que devuelva el producto en vez de un mensaje
POST /api/Comprobantes -> que devuelva el comprobante en vez de un mensaje

GET(all) /api/Clientes -> (para los activos) parámetros opcionales para filtrar por nombre apellido y dni

GET(all) /api/Clientes -> traer todos los inactivos

PUT /api/Clientes -> que muestre en el body los datos "antiguos" para actualizar
PUT /api/Productos -> que muestre en el body los datos "antiguos" para actualizar
PUT /api/Comprobantes -> que muestre en el body los datos "antiguos" para actualizar

PUT /api/Clientes -> que se carguen los datos antiguos a editar, que devuelva el cliente en vez de un mensaje
PUT /api/Productos -> que se carguen los datos antiguos a editar, que devuelva el producto en vez de un mensaje
PUT /api/Comprobantes -> que se carguen los datos antiguos a editar, que devuelva el comprobante en vez de un mensaje

DELETE /api/Clientes -> que devuelva el cliente en vez de un mensaje
DELETE /api/Productos -> que devuelva el producto en vez de un mensaje
DELETE /api/Comprobantes -> que devuelva el comprobante en vez de un mensaje
